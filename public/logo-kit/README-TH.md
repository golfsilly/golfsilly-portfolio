# Golfsilly Cyber Portfolio — คู่มือชุดภาพ

ชุดภาพนี้ใช้คนเป็น Dev, ตัว G พลาสมา และแสงฟ้า–ม่วง–ชมพูร่วมกัน ฝาโน้ตบุ๊กเป็นสีดำเรียบ ไม่มีโลโก้และไม่มีเครื่องหมายโค้ด

## เลือกไฟล์อย่างไร
- `00-master` : ภาพต้นฉบับโปร่งใสจากเครื่องมือสร้างภาพ 1254×1254px เก็บไว้เป็นแหล่งต้นฉบับ
- `01-logos/primary` : โลโก้หลัก ใช้ที่ความกว้าง 250px; ไฟล์ 500w สำหรับหน้าจอความละเอียดสูง
- `01-logos/horizontal` : โลโก้แนวนอนสำหรับ Header ใช้ที่ความกว้าง 240px; ไฟล์ 480w สำหรับหน้าจอความละเอียดสูง
- `01-logos/stacked` : โลโก้แนวตั้งสำหรับ About หรือ Footer ใช้ที่ความกว้าง 180px; ไฟล์ 360w สำหรับหน้าจอความละเอียดสูง
- `01-logos/mark` : สัญลักษณ์เต็ม ไม่มีชื่อ ขนาด 1254, 512 และ 180px
- `02-favicons` : PNG ขนาด 16, 32, 48, 64px และ ICO รวม 4 ขนาด ใช้ภาพเต็มตามที่เลือก รายละเอียดคนจะไม่ชัดในขนาดเล็ก
- `03-hero` : ภาพหน้าแรก Desktop และ Mobile ไม่มีข้อความฝังในภาพ
- `04-about` : ภาพ About แนวตั้งและรูปโปรไฟล์จัตุรัส
- `05-backgrounds` : พื้นหลังวงจรและพลาสมาสำหรับวางเนื้อหาด้านบน
- `06-social` : ภาพแชร์ลิงก์ 1200×630px

## พื้นหลังและความคมชัด
ไฟล์ `transparent.png` มีช่อง alpha จริง ส่วน `dark.png` มีพื้นหลังสีเข้มในภาพ เลือก transparent เมื่อต้องวางบนสีพื้นอื่น ธีมที่แนะนำคือพื้นมืดเพราะสีเสื้อและโน้ตบุ๊กเข้มมาก

ไม่ตัดส่วน G หรือยืดภาพแยกตามแนวตั้ง/แนวนอน ใช้ความกว้างพร้อมความสูงอัตโนมัติ เว้นพื้นที่รอบโลโก้อีกประมาณ 1/4 ของความสูงสัญลักษณ์เมื่อพื้นที่เอื้ออำนวย ใน Header ใช้ช่องว่างอย่างน้อย 12px จากองค์ประกอบข้างเคียง

## การวางข้อความหน้าเว็บ
Desktop: ใช้ข้อความในพื้นที่ซ้ายไม่เกินประมาณ 50% ของภาพ ภาพประกอบหลักเริ่มราว 55% ของความกว้าง
Mobile: ใช้พื้นที่ด้านบนประมาณ 30% สำหรับหัวเรื่อง หากข้อความยาวให้แยกเป็นบล็อกเหนือภาพ
About: วางข้อความเป็นคอลัมน์ข้างภาพบน Desktop และเรียงด้านบน/ล่างบน Mobile
พื้นหลัง Section: วางข้อความในช่วงกลางที่มืด หลีกเลี่ยงทับเส้นพลาสมาที่ขอบ

## สีและตัวอักษร
พื้นหลัก #070A14 · ข้อความ #E8F7FF · Cyan #00D9FF · Violet #8A2BFF · Magenta #E53BFF
รหัสสีเป็นค่าแนะนำสำหรับหน้าเว็บ ภาพมีการไล่สีและแสงหลายเฉด
ชื่อ Golfsilly ใช้ Bahnschrift น้ำหนัก 600 ระยะตัวอักษรปกติ เรนเดอร์รวมใน PNG แล้ว ไม่จำเป็นต้องติดตั้งฟอนต์เพื่อใช้ภาพ และไม่ได้แนบไฟล์ฟอนต์

## การส่งออก
ภาพประกอบมีทั้ง PNG สำหรับเก็บต้นฉบับส่งออกและ WebP คุณภาพ 90 สำหรับเว็บ โลโก้มีรุ่น 1x / 2x เพื่อช่วยความคมบนจอ Retina
ไฟล์ขนาดส่งออก 1920×1080 และ 1200×1500 ผ่านการปรับขนาดจากภาพที่เครื่องมือสร้าง ไม่ใช่การอ้างว่าทุกภาพถูกสร้างที่ความละเอียดนั้นโดยตรง ต้นฉบับสัญลักษณ์มีความละเอียด 1254×1254px
ไม่มีภาพผลงาน ลูกค้า ประสบการณ์ หรือข้อมูลส่วนตัวสมมติในชุดนี้

เปิด `preview.html` เพื่อดูทั้งชุด เปลี่ยนพื้นหลังตรวจ PNG โปร่งใส และดาวน์โหลดไฟล์แยกได้ ส่วน `manifest.json` ระบุขนาดและชื่อไฟล์ทั้งหมด
